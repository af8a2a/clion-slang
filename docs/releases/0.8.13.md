# 0.8.13 — HLSL SM 6.6 descriptor heap references

`ResourceDescriptorHeap` and `SamplerDescriptorHeap` now receive builtin variable
highlighting and a clickable **HLSL Reference: Shader Model 6.6 Dynamic Resources**
link in hover documentation. The bundled enhanced slangd recognizes unresolved
variable expressions for these two HLSL globals; resolved user variables, parameters,
fields and namespace globals keep their normal behavior. Comments, strings, inactive
code and macro names are not classified by spelling.

Light / IntelliJ Light use the Rider constant accent (cyan `0093A1`, bold) for
**Semantic / Other built-in symbol**. Existing user overrides take precedence.
The standard `defaultLibrary` semantic modifier is negotiated; clients that do not
advertise it keep the previous token legend and zero modifier bits.

This release includes the 0.8.12 declaration Ctrl-hover improvement. Install the ZIP,
restart CLion, and select **Bundled enhanced slangd**. These are editor features:
this patch does not implement HLSL compilation or hide unsupported-code diagnostics.
