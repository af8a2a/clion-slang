# 0.8.2 — Rider-style field hover

Struct field declarations and references now show visibility, specialized field type and
bold name, an indented declaring struct, separate size/alignment/offset rows, and a compact
source filename link. The layout values come from the bundled compiler's natural layout.
The user's BuildReGIRPush.lightCount reports size 4, alignment 4 and offset 0.

The bundled Windows x64 slangd adds patch 0008 after the existing seven patches. It handles
generic substitution, inherited members, arrays, matrices and enum fields; retains folded
constant initializers and docs; and marks unknown layouts or static instance offsets explicitly.
Select Bundled enhanced slangd in Slang settings after upgrading. External official servers
keep their original hover content. The source selector and existing struct presentation remain.

Presentation follows the active editor colors and Chinese/English IDE locale, without selecting
a different scheme. CLion retains ownership of popup chrome, fonts and actions.
