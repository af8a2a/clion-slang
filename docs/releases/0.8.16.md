# 0.8.16

Slang interface declarations now have a gutter navigation marker when indexed
derived types are available. Hover for the count; click to navigate or choose
from direct and indirect derived interfaces, structs and classes. The native
list includes type names, namespaces and source paths.

The reverse inheritance index covers unopened files and unsaved document edits,
preserves generic type declaration offsets, and uses the existing build-output
symbol filter. Generic parameter constraints are not inheritance edges.
Qualified and nearest enclosing type names take precedence; ambiguous simple
names are omitted. Cycles and multiple inheritance paths do not duplicate items.

This first version provides gutter markers, not Rider's inline Code Vision row.
It indexes explicit declaration base clauses, independently of slangd. Type
aliases, extension-based conformances, generic specialization constraints and
active preprocessor-variant filtering are not semantically resolved. A globally
unique simple name is a navigation candidate even when its import visibility
cannot be established by this local declaration index.

Closing a non-local virtual Slang editor no longer attempts to convert its URI
to a filesystem path during preprocessor-preview cleanup.

Validation: focused native-platform index, gutter, navigation, unsaved-edit,
namespace ambiguity, cycle, serialization and existing symbol-search tests.
Interactive CLion popup appearance still needs manual verification.
