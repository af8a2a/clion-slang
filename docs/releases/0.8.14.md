# 0.8.14 — Typed HLSL descriptor heaps

0.8.13 supplied colors and reference links for the SM 6.6 descriptor heaps, but its
unresolved-name fallback left `undefined identifier` diagnostics visible. The bundled
server now resolves both names to real core-library declarations with distinct sampler
and resource element types, and performs ordinary type checking through constrained
resource constructors. No error messages are hidden or filtered.

This fixes the reported `resolveUniform(SamplerHandle)` and
`resolveNonUniform(SamplerHandle)` functions. Sampler/comparison states, textures,
structured/raw buffers, constant/texture buffers and acceleration structures are covered.
Wrong heap kinds, invalid indices and scalar assignments still report errors. Resolved
user symbols retain their behavior; builtin coloring and HLSL reference links remain.

## 中文

修复 `SamplerDescriptorHeap[handle.index]` 及 `NonUniformResourceIndex` 用例的
undefined identifier 红线。自带增强 slangd 已补齐两类 heap 的声明、索引与资源转换类型；
混用采样器/资源 heap 和其他类型错误仍会报错。安装后重启并使用自带增强 slangd。
该更新只影响插件语言服务器；工程构建所调用的独立 Slang 编译器仍保留其自身行为。
