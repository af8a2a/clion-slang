# 0.8.9 — Precise Ctrl-hover ranges in macro definitions

Ctrl-hover previously underlined the entire #define directive because the flat PSI tree used the
highlighting lexer's whole-directive token as one leaf. Definition requests already used the correct
identifier offset; the underline's source range was too broad.

The parser now uses a PSI-only lexer that splits preprocessor directives into identifier-sized leaves.
Macro names, callees and member names have separate ranges, including in backslash-continued macros.
The highlighting and symbol-indexing lexer remains unchanged. Lexer save/restore and state-based
restarts retain exact UTF-16 ranges. The 0.8.8 duplicate-inlay-hint fix is also included.

Validation includes macro identifiers, CRLF continuations, Unicode offsets, position restoration,
state-based restarts, ordinary syntax and include-path preservation. A native CtrlMouseData platform
regression test has been added; its execution requires the JetBrains test framework, which is not
available in the local offline cache. Interactive installed CLion validation remains unperformed.
