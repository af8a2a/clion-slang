# 0.8.11 — Member access colors

Field declarations and accesses now use the configurable Slang semantic Field/property color.
In the bundled Rider Light palette, `ui` remains neutral and `textColor` in `ui.textColor` uses
purple (`#300073`). Chained fields and vector/matrix selectors (`ui.pxCursor.x`, `.xy`, `._m00`)
use the same member color. Methods retain the function color; namespace globals remain variables.
Classification comes from compiler AST declarations, so a same-named parameter or local variable
is not mistaken for a field. The existing standard `property` role works with stock and extended
semantic-token legends; no client capability upgrade is required.

The enhanced runtime includes patch 0011. Custom external servers keep their own token behavior.
Real-server regression covers generic, implicit, static and chained fields, same-named locals,
methods, namespace globals, selectors and unsaved UTF-16/CRLF edits. UI appearance in an installed
IDE has not been independently verified.

## 中文

`A.b` 的对象和成员现在采用不同颜色：Rider Light 下对象保持普通文字色，字段及向量分量为深紫色。
支持连续成员访问、泛型字段、隐式字段和静态字段，方法与命名空间变量保持各自语义颜色。
安装后重启 CLion，使用插件自带的增强 slangd 即可。
