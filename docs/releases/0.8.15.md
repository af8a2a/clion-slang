# 0.8.15 — Slang 2026.19 and dynamic resource heap resolution

Upgrade the bundled enhanced language server from the 2026.4.2-based snapshot to
[official Slang 2026.19](https://github.com/shader-slang/slang/releases/tag/v2026.19),
commit `0fb6b7587a94fa33d88141ec9930766eedc6f59a`.

The reported `getDescriptorFromDynamicResourceHeap<T>(handle,
BindlessDescriptorOptions.VkMutable)` resolver now uses the upstream standard-library
implementation. Its generic constraint, required option parameter and target-specific
behavior are retained. The old server reproduced undefined-identifier and secondary
type errors for this source; the upgraded server accepts the valid resolver.

The upstream core library also replaces the prior custom HLSL descriptor heap types.
Existing editor features are migrated as one reproducible patch in
`patches/slang/2026.19`; historical patches remain available for old releases. The port
preserves upstream's search-path buffer lifetime fix and adapts builtin provenance to
generic declaration wrappers. No diagnostics are filtered.

两类 DescriptorHeap 改用新版官方类型实现，保留已有高亮、参考链接、导航、布局悬停和

项目自己的 Slang 编译器或显式选择的外部 slangd 不会被替换。

## Validation

- All fifteen real-server smoke suites passed against the staged 2026.19 binaries.
- The actual reported resolver body, explicit/inferred generics, acceleration structures,
  samplers and textures pass diagnostic/hover checks. Wrong generic types, missing arguments,
  mismatched handles and wrong option types still report errors; unsaved UTF-16/CRLF edits
  clear stale diagnostics. These checks cover LSP semantic diagnostics, not every later
  compiler/code-generation validation phase.
- Twenty-three focused tests passed using the installed CLion 262 libraries and refreshed
  real-server hover samples, including native documentation rendering and palette mapping.
- HLSL fixtures now terminate structs with semicolons; string coverage uses a valid type.
  Diagnostic tests drain configuration responses before taking their initial snapshot.
- Source patch replay and static CRT/import/manifest checks passed. New cmark, fast_float
  and mimalloc license notices accompany the runtime. Explicit UTF-8 flags avoid MSVC
  C4819/C2220 on Chinese Windows.
- Interactive IDE behavior and a full Metallic shader/game build were not run.
