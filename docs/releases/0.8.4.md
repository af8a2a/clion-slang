# 0.8.4 — Native Slang symbol search

Slang declarations now appear in CLion's Search Everywhere Symbols tab and Go to Symbol.
The reported `streamNormalStride` function is indexed with its parameter signature and source
position. Results include overloads, container/file information, kind icons and navigation.

A content-dependent file index covers `.slang` / `.slangh` project files, including unopened
files, independently of slangd. It indexes functions, types, namespace/type members, global
declarations and aliases while skipping executable bodies and call sites. IDE search scopes,
matching and index/document updates are reused. See [symbol search](../symbol-search.md) for
usage and scanner limitations, including conditional branches and macro-generated declarations.

Validation: 128 available JUnit tests passed, 1 optional test skipped. The actual Metallic
corpus passed declaration/offset checks across 126 files, producing 2,579 declarations and
exactly one `streamNormalStride` result. The plugin built against installed CLion 2026.2.2.
The 0.8.4 archive includes the index/contributor registrations and classes; runtime checksums
are unchanged and verified. `git diff --check` passed.

Native platform integration tests are included but could not run: the JetBrains test-framework
artifact was uncached and online repository access failed. A live installed Symbols popup check
is not claimed. The existing local-262-SDK versus declared-261-minimum and Java-21 build warnings
remain. This release does not modify the bundled compiler or publish new compiler patches.
