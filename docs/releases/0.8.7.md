# 0.8.7 — Builtin documentation references

Slang/HLSL builtin global functions and constants now offer clickable official documentation in
hover popups, using CLion-style symbol names, site labels and an external-link arrow.

The packaged offline catalog covers 391 names. HLSL intrinsics prefer Microsoft Learn; Slang-specific
functions, constants and overload groups link to Slang Documentation. Existing hover signatures,
documentation and source ranges are preserved. Same-named user declarations receive no references.

Bundled Windows x64 slangd includes patch 0009 for semantic builtin provenance. External servers
retain conservative compatibility when an unambiguous absolute synthetic source is available.
See [coverage and verification](../builtin-documentation.md).
