# Slang CLion 0.7.0

## Highlights

- **Slang Rider Light**: a selectable light preset mapped from Rider's exported C++ colors,
  also supplying Slang-only defaults for Light / IntelliJ Light. Covers lexical and semantic
  roles, structured buffers, generic type arguments and preprocessor branches. Explicit user
  overrides and dark themes are preserved.
- Separate colors for `#include` directives and header paths, and for the `StructuredBuffer` /
  `RWStructuredBuffer` family and checked generic type arguments.
- Optional compiler-backed preprocessor branch display, compilation-context discovery/selection,
  Shader Variant manifests with CMake export, and temporary define/undefine branch preview.
- English/Chinese README, protocol documentation, reproducible server patches and regression tests.
- Plugin metadata and release tag now agree on **0.7.0**, above the previously published 0.6.0.

## Installation and migration from 0.6.0

Download `slang-clion-0.7.0.zip` and install it using **Settings | Plugins | Install Plugin from
Disk**. Requires CLion 2026.1.3 or newer (declared minimum build 261.25134).

**This is a plugin-only ZIP; it does not bundle slangd or compiler libraries.** Configure an
external `slangd` under **Settings | Languages & Frameworks | Slang**. Stock slangd supports the
standard LSP features. Extended branch display and structured-buffer/generic classification require
the appropriate patches from this release's
[server patch instructions](https://github.com/af8a2a/clion-slang/blob/v0.7.0/patches/slang/README.md).
Apply patches 0001–0005 in order to the documented pinned upstream revision for all extensions.

The earlier 0.6.0 bundled server and its custom field/function hover, document-local reference and
document-highlight patches are **not** part of the current patch chain. The earlier custom comment
folding implementation is also not included. Standard hover/references/highlights depend on the
selected server and IDE support; this release does not promise feature parity with that old bundle.

Choose **Slang Rider Light** under **Settings | Editor | Color Scheme** for the supplied palette.
No changes to your original Rider export, saved custom scheme, or project macros are required.

## Validation and scope

- Plugin ZIP built with the installed CLion 2026.2.2 SDK / JBR 25; Java output remains `--release 21`.
  The declared 2026.1.3 baseline has not changed; this release has not been newly verified against it.
- 84 non-IDE-fixture JUnit tests passed, including real patched-slangd protocol checks and the
  Rider attribute mapping regression. The 35 reference attributes were checked against the supplied export.
- Full IDE-fixture tests remain blocked by the unavailable JetBrains test-framework dependency.
  No new GUI acceptance or Plugin Verifier run is claimed.
- A SHA-256 sidecar is provided with the ZIP. Build outputs are Release assets, not source files in Git.
