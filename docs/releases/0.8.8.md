# 0.8.8 — Remove duplicate macro parameter hints

Repeated macro expansions in slangd can emit identical inlay hints at the same position in a macro
definition. In Metallic's AutoExposure.slang, resolveDescriptor(gParams.source) received three
identical handle: hints in one textDocument/inlayHint response.

The plugin now removes structurally identical hint objects within each correlated response, keeping
the first occurrence and the original order. Position, label parts, kind, padding, tooltip, text edits,
commands and resolve data all participate in equality. Different hints remain intact. No deduplication
state survives a response, so later requests still return their hints normally. Both bundled and
external slangd use the same adapter; the bundled compiler binaries are unchanged from 0.8.7.

Validation: the captured real AutoExposure response goes from 72 hints to 69, with the reported
handle: location going from three hints to one. All distinct hints are preserved. 152 tests passed,
with one optional test skipped, including request correlation, repeated requests, structured labels,
metadata preservation and UTF-8 Content-Length framing. The installed CLion popup has not been
manually verified.

## 中文

修复宏定义处重复的形参提示。slangd 多次展开同一宏时会在同一源码位置返回重复提示，
现在插件仅合并单次响应内完全一致的提示，并保留顺序、不同位置和附加信息。
适用于自带版及外部公版 slangd，无需修改 Shader 或关闭形参提示。
