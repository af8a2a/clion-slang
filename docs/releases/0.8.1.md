# 0.8.1 — Rider-style struct hover presentation

Struct hover layout properties no longer merge onto one line in CLion's native documentation
popup. The plugin formats the recognized bundled-server response with explicit line breaks:
size, alignment, nonzero wasted padding and optional array stride each occupy a separate row.
Zero padding is omitted, matching Rider, and numbers no longer have inline-code backgrounds.

The type name is bold, the namespace is indented beneath it, and colors follow the active Slang
editor scheme. Labels follow the IDE language (Chinese or English). The footer shows a compact
filename with its line number in the title; the original file URI and line fragment remain intact.
Documentation, generic type spelling, layout values, and hover ranges are preserved.

The native popup still belongs to CLion. The bundled/external selector and patched Windows x64
runtime from 0.8.0 remain included; the compiler binary did not change in this release.

Validation uses the installed CLion 2026.2.2 LSP documentation splitter, Markdown converter and
Swing layout, plus light/dark standalone renders of actual GPUDrivenPreviewParams and test struct
responses. Unit tests cover custom colors, localization, escaping, padding/stride, link targets,
request correlation, and unchanged fallback formats. Full IDE fixture tests remain unavailable
because the JetBrains test-framework dependency is not cached; a live installed-popup visual
check is not claimed by the standalone rendering probe.

Final checks: 108 JUnit tests passed, 1 optional test skipped, 0 failures. The 0.8.1 ZIP contains
the new presentation class and checksum-verified runtime; its extracted server passed the struct
hover smoke suite. `git diff --check` passed.
