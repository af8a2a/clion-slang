# 0.8.10 — Macro expansion previews

Hover macro uses to see a Rider-style definition, **Expansion preview**, and a compact source-file link.
The bundled compiler records actual final expansion tokens, supporting nested and parameterized macros,
variadic forwarding, token pasting, stringization, empty bodies, recursion suppression and redefinitions.
The popup follows the active theme and IDE language. Unavailable previews and truncated expansions are
explicitly labeled. Official/external servers retain their original hover behavior.

Includes the 0.8.8 repeated macro parameter-hint fix and 0.8.9 precise Ctrl-hover ranges in macro bodies.
The bundled Windows x64 runtime now contains patches 0001–0010.
See [coverage and validation](../macro-hover.md).

## Language server recovery

Fixes semantic colors remaining absent after a language-server startup failure. Project-root
and dependency refreshes now use a separate 2-second quiet window, a 10-second restart cooldown,
and defer while the server initializes or the IDE indexes. Unexpected shutdowns receive at most
three recovery attempts; a session that runs for 30 seconds renews that budget. Normal/manual
shutdowns do not trigger recovery. Dependency invalidation also works with branch overlays disabled.

The reported `ContextScatter<TSink : IScatterSink>` declaration already produces the correct
semantic tokens in both the installed and staged enhanced servers. The observed IDE log instead
shows repeated model-refresh restarts followed by `ConcurrentModificationException` in
`LspDocumentSyncManager.forEachOpenedFile`, leaving the server stopped. This plugin change reduces
restart contention and recovers from transient failures; it does not modify that IDE implementation.
Regression coverage includes the restart policy and real-server tokens for the declaration,
type parameter, interface requirement, and field type. Interactive IDE recovery still needs verification.

Validation: 13 focused JUnit tests passed using the installed IDE libraries and bundled JUnit;
real-server smoke passed against both installed and staged slangd. `buildPlugin --offline` passed
on the configured 2026.1.3 baseline. The normal Gradle test task could not resolve the JetBrains
platform test-framework dependency because the repository redirect hosts failed DNS resolution.
