# 0.8.0 — Bundled enhanced slangd and server selection

Windows x64 installations now include the patched language server, matching compiler and GLSL
module DLLs. Installing the plugin can therefore enable struct layout and type alias hover without
replacing files in the user's SDK. The bundle includes patches 0001–0007 and their license notices.

**Settings | Languages & Frameworks | Slang | Language server** selects bundled enhanced or external
/ official slangd. Apply restarts the language service. External mode retains automatic discovery
and manual paths; switching modes preserves external configuration. Existing automatic settings
migrate to bundled mode on supported hosts, while old manual configurations remain external.

The compiler runtime is statically linked. Startup verifies the packaged executable and DLLs and
reports missing/corrupt files without falling back to another server. Source and packaging instructions
are in [bundled slangd](../bundled-slangd.md).

## Validation

- Built and packaged against the installed CLion 2026.2.2 SDK; configuration-cache reuse passed.
  The declared 2026.1.3 baseline and Java 21 bytecode remain unchanged. Gradle warns about this
  difference from the local SDK; a fresh Plugin Verifier run against the baseline was not performed.
- JUnit: 99 passed, 1 optional test skipped, 0 failures using the installed IDE libraries, including server selection/migration,
  runtime integrity checks and real-server LSP4J tests against the server extracted from the ZIP.
  This invocation excludes the two IDE fixture test classes; the optional CMake-exporter test has
  no supplied fixture. Full Gradle test execution was blocked by the unavailable cached JetBrains
  test-framework dependency.
- Seven Python real-server suites passed against the staged bundle: preprocessor trace, contexts,
  variants, preview, structured buffers, type aliases and structs. The struct suite also passed
  against the final ZIP's extracted server.
- The final ZIP's server returned natural layout Size 336, Alignment 4, Padding 0 for the actual
  `GPUDrivenPreviewParams` parameter type at `hzbMipOffset` in the user's GPU-driven shader.
- ZIP payload hashes match its manifest. Actual CLion settings interaction and native hover popup
  rendering still need an IDE-level visual check; protocol checks do not claim to verify UI rendering.
